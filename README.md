# 🪨📄✂️ Pedra, Papel e Tesoura – Jogo em C

Jogo desenvolvido em C com modos Singleplayer e Multiplayer, Ranking, Tutorial e Pontuação Automática. O(s) jogador(es) pode(m) escolher entre melhor de 3 ou melhor de 5. Ademais, o ranking é salvo em arquivo e atualizado ao final de cada partida, lá você poderá consultar sua pontuação.

## 🎮 Funcionalidades
- Singleplayer (vs Computador)
- Multiplayer (2 jogadores com entrada secreta usando `_getch()`)
- Sistema de ranking com pontuação (10 por vitória, 5 por empate, 0 por derrota)
- Armazenamento em `ranking.txt`
- Menu inicial, tutorial e créditos
- Estrutura modular com múltiplos arquivos `.c` e `.h`

## ⚙️ Tecnologias e Recursos Utilizados
- Linguagem C
- Modularização com múltiplos arquivos
- Manipulação de arquivos (`fopen`, `fscanf`, `fprintf`)
- `rand()` para jogadas da CPU
- `_getch()`, `Sleep()`, `system("cls")` para interação no console
- Strings e comparação (`strcmp`, `strcpy`)
